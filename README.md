# Dragon Drop has moved

This repository only exists so that copies of Dragon Drop installed before version 0.1.8
(when it was called AI Mapmaker) can find their update. There is no source code here.

- Installed copies update themselves from the release in this repository, to
  version 0.1.9. From then on they look for updates at the new home.
- The project itself lives at **https://github.com/DJ-JackJack/dragon-drop**.
  Get the latest installer from its Releases page.
- If you cloned this repository, clone the new one instead; do not pull into the old folder.
